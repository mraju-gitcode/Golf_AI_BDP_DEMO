## Create a new watering program
Video: "Creating a program in CirrusPRO".
1. Open the Programs view and select New Program.
2. Name the program (for example, Practice Area).
3. Add the holes or areas and their stations to the program.
4. Set the start time, days and run times, then save.
5. Run a test cycle to confirm the stations respond.
